# Illustrative crop quality/freshness assets

Six AI-generated photographic triptychs, created with the built-in image-generation tool on 17 October 2026. Each PNG contains three equally sized horizontal panels; the UI displays one panel per A/B/C card using CSS background positioning. Original files remain intact; no separate image crops were fabricated as measurements.

These are **illustrative appearances, not validated official grading examples**. They do not certify edibility, moisture, toxins, crop variety, safety or an official UNBS/EAC grade. They are not a vision-model training set. Price multipliers remain separate application assumptions, and buyers/farmers must agree quality directly.

Prompt pattern: three equal square photographic samples on white, same lighting/angle/portion sizes, no labels or certification marks. Subjects:

- Beans: intact sorted beans → some broken/shrivelled → more broken/shrivelled.
- White maize grain: intact kernels → some broken/uneven → more broken/shrivelled.
- Sorghum and millet: uniform intact grain → some uneven/broken → more broken/shrivelled.
- Fresh cassava: intact roots/white cut ends → minor skin abrasion/drier ends → more shrivelling/dry ends.
- Leafy vegetables: crisp green leaves → some wilting/yellow edges → more wilting/yellowing.

Dry grain and beans show quality differences, not ripeness. Fresh cassava and leaves show freshness appearance. No mould/slime examples were requested. Absence of visible mould is not evidence of food safety.

The maize triptych was edited with the built-in image tool after inspection to remove dark/mould-like spots. Its middle/right panels now show clean kernel breakage, light cream colour and shrivelling only, preserving the original three-panel composition.
